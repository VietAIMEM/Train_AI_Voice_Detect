This is the report for my graduation project, focusing on the development of an AI-powered mobile application for detecting potential scam calls through real-time analysis of voice characteristics and conversation content. The project combines speech recognition, natural language processing, and deep learning models to assess scam-related risks during phone conversations.

The complete project report has been uploaded to the `VietAIMEM/VoiceScanAI_ScamDetect` repository for reference, including the research methodology, system architecture, model development, experiments, and evaluation results.
